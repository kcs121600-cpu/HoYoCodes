# HoYo Codes — 개인용 안드로이드 리딤코드 알리미

붕괴: 스타레일 / 젠레스 존 제로의 새 리딤코드를 주기적으로 수집하고, 알림에서 **한 번 눌러 Chrome의 공식 등록 페이지로 이동**하는 소규모 네이티브 Android 앱입니다.

## Lenovo Legion Y700 3세대 화면 대응 (v1.2.0)

- 기기 기준: 약 8.8인치, 2560×1600, **16:10** 화면. 실제 화면 좌표는 고정 픽셀 대신 Android **dp**로 자동 계산합니다.
- **세로 모드:** 기존 스마트폰형 한 열 구성, 본문 최대 680dp로 중앙 배치. 코드가 화면 전체 폭으로 과하게 늘어나지 않습니다.
- **가로 모드:** 화면이 충분히 넓으면 좌측 326dp에 게임 선택·검사 상태·빠른 이동, 우측에 코드 목록을 나누는 2분할 UI로 전환합니다.
- 우측 목록은 공간이 충분하면 카드 **2열**, 분할 화면/글씨 크기 변경 등으로 폭이 좁아지면 자동으로 **1열**로 바뀝니다.
- 주요 버튼 터치 영역을 약 48dp 이상으로 키웠고, 화면 방향 전환 시 선택 중인 게임 및 상태 탭을 유지합니다.
- 앱 패키지 ID는 그대로 유지하면서 `versionCode`를 2로 올렸습니다. **동일한 서명 키로 기존 앱을 업데이트하면** 사용 완료 기록이 유지됩니다. 서명 키가 다르면 설치가 거부될 수 있으므로 업데이트 전 JSON 백업을 권장합니다.
- 중국 내수판 / 글로벌 롬 / 화면 확대·글꼴 배율에서 실제 화면 배치는 달라질 수 있어 Y700 기기 실물에서 최종 검증해야 합니다.

## 제공 기능

- **1/3/6/12/24시간** 간격 백그라운드 코드 확인 (기본 **1시간**) 및 앱 내 즉시 확인
- 공개 소스 2곳에서 스타레일 / 젠존제 코드 수집, 게임+코드별 중복 제거
- 알림의 **첫 코드 등록하기** 버튼을 누르면 Chrome에서 코드가 URL에 포함된 공식 등록 페이지 열기
- 로그인 정보/쿠키/비밀번호는 **APK에 저장하지 않음**. Chrome에 이미 로그인한 호요버스 공식 계정 세션 사용
- `새 코드` · `확인 필요` · `사용한 코드` · `만료` 탭
- 사용 완료 상태는 다음 수집 때도 유지, **브라우저를 연 경우 자동으로 사용 완료 처리하지 않음**
- 코드 수동 추가, 클립보드 복사, JSON 내보내기/가져오기 (사용 이력 백업)
- 광고, 앱 자체 계정, 비공식 등록 API 호출, 접근성 권한 **없음**

## Windows에서 APK 빌드 (Android Studio 설치 필요)

1. [Android Studio](https://developer.android.com/studio)를 설치하고 **SDK Manager**에서 **Android SDK Platform 35**를 설치합니다. JDK 17 이상이 필요합니다(Android Studio 포함).
2. 이 폴더를 압축 해제합니다.
3. `build_windows.bat`를 실행합니다. 첫 빌드에서 공식 Gradle 8.9가 다운로드됩니다. 인터넷 연결이 필요합니다.
4. 빌드가 성공하면 폴더 루트에 `HoYoCodes-debug.apk`가 생성됩니다.
5. APK를 Y700 태블릿에 복사해서 설치하고, 알림 권한을 허용합니다.

또는 Android Studio에서 이 폴더를 열고 **Build > Build APK(s)**를 실행할 수 있습니다. 개인용 설치이므로 `assembleDebug` 산출물을 사용합니다.

## 사용 방법

1. 앱 첫 실행 시 코드 확인과 1시간 간격의 백그라운드 검사 작업이 설정됩니다. 안드로이드 절전 정책으로 실제 실행은 지연될 수 있습니다.
2. Chrome에서 스타레일/젠존제 **공식 교환 사이트**에 로그인해 둡니다. 호요랩 앱 로그인과 Chrome 로그인은 별개일 수 있습니다.
3. 새 코드 알림에서 **첫 코드 등록하기**를 누르거나 새 코드 탭의 **Chrome에서 코드 자동 입력**을 누릅니다.
4. 공식 사이트에서 코드 입력 필드가 채워졌는지 확인한 뒤 **최종 등록 버튼은 직접** 누릅니다.
5. 앱으로 돌아와 **사용 완료**를 눌러 기록을 저장합니다. 아직 확인하지 못했으면 `확인 필요`에 남겨둡니다.
6. 중요한 사용 이력은 `설정 > JSON 백업 내보내기`로 파일에 보관하세요.

## 중요한 제한 사항

- **최종 교환 버튼은 자동으로 누르지 않습니다.** 단순히 공식 URL에 코드를 실어 Chrome을 열 뿐입니다.
- 사용자 계정 로그인 상태에 따라 사이트에서 다시 로그인을 요구할 수 있습니다.
- 사이트 구조가 변경되면 자동 입력이 되지 않을 수 있습니다. 이를 대비하여 APK가 **코드를 클립보드에도 복사**하므로 붙여넣을 수 있습니다.
- Android 절전/Doze 및 제조사별 배터리 관리 때문에 검사가 정확히 지정한 시간에 실행되지 않을 수 있습니다. **휴대폰 전원 OFF, 앱 강제 종료 상태에서는 작동하지 않습니다.**
- 공개 API는 누락, 만료 코드, 지역 한정 코드, 일시 장애가 있을 수 있습니다. 특히 **짧게 유효한 방송 코드**는 놓칠 수 있으며, 1시간 간격이라도 Android 절전 정책으로 지연될 수 있습니다.
- 공개 소스가 누락한 코드는 사용자가 수동으로 추가할 수 있습니다.
- APK에서 '만료'는 사용자가 직접 표시하는 값입니다. 출처에 코드가 잠시 보이지 않는다는 이유만으로 만료 상태로 바꾸지 않습니다.
- Google Play에 배포하거나 인증 정보를 제3자 서버에 전달하도록 구현하지 않았습니다.

## 검증 범위

- 본 소스의 순수 Java `CodeRules` 6개 단위 검사는 통과했습니다.
- 현재 작성 환경에 **Android SDK와 외부 다운로드 네트워크가 없어 APK 바이너리 빌드 및 실기기 검증은 수행하지 못했습니다.**
- 실제 Chrome 로그인 세션 재사용, 두 공식 사이트의 코드 자동 채움, Android 제조사별 백그라운드 실행은 실기기에서 확인해야 합니다.

## v1.2.0 신규 기능 — 공식 방송 코드 보조 감시

- 미요우셔 공식 방송 코드 정보를 모아 제공한다고 밝힌 제3자 `GameCal`의 게임별 이벤트 API를 세 번째 수집처로 추가했습니다.
- **방송 코드로 명시된 이벤트만** 읽고, 이미 만료된 이벤트 및 방송 일정 이벤트를 제외합니다.
- 새 방송 코드를 발견하면 기존의 `새 코드` 탭과 알림에 합쳐지고, 코드 출처가 `방송 한정 · GameCal`로 표시됩니다. 사용 완료 기록은 그대로 유지됩니다.
- 사용자가 앱을 직접 업데이트하지 않아도, 출처가 새 코드를 제공하면 다음 검사에서 자동으로 반영됩니다.
- **제3자 출처는 방송 중 실시간 제공이나 누락 없는 수집을 보장하지 않습니다**. 원본 공식 방송 API와 개별 서버에서의 코드 등록 가능성은 실기기 검증이 필요합니다.

## v1.2.0 신규 기능 — 앱 업데이트 알림

- `설정 > GitHub 업데이트 저장소 설정`에서 **본인이 소유한 공개 GitHub 저장소**를 `owner/repo` 형식으로 지정하세요.
- 해당 저장소의 `Releases`에 새 버전의 서명된 APK가 업로드되면 **하루 한 번까지 확인해 알림**을 띄웁니다(평소 코드 자동 검사 실행 시 함께 확인).
- `설정 > 앱 업데이트 확인`으로 즉시 확인할 수도 있습니다.
- 알림을 누르면 **GitHub의 APK 다운로드 링크**가 열립니다. 다운로드 후 **Android 설치 확인은 직접** 해야 합니다. 앱이 몰래 APK를 설치하지 않습니다.
- 저장소와 Release가 아직 없으면 업데이트 알림이 작동하지 않습니다.
- 최초 공개 저장소 생성, APK 배포 서명키 및 GitHub Actions 설정은 [PUBLISH_UPDATES_KO.md](PUBLISH_UPDATES_KO.md)를 따라 진행하세요.
- 중요한 사용 기록 보존을 위해 **동일한 앱 ID, 동일한 서명키, 증가하는 versionCode**가 필요합니다. 기존 debug 앱은 새 release 키로 덮어쓸 수 없으므로 JSON 백업 후 교체해야 할 수 있습니다.

## 검증 주의

- 이번 환경은 Android SDK와 Android 기기가 없고 네트워크 패키지 다운로드가 불가능해 **실제 APK 컴파일/설치와 외부 API의 현재 응답 검증이 완료되지 않았습니다.**
- 코드를 수집하는 외부 서비스/방송 피드에서 장애가 발생할 수 있습니다. 앱 설정에서 마지막 오류 내역을 확인하세요.
- 방송 피드는 공식 방송의 정보를 **제3자가 재가공한** 것입니다. HoYoverse의 공식 보증 서비스가 아닙니다.
